# EDA report
EDA(Electronic Design Automation)，中文為 電子設計自動化 
>EDA 是一套從設計、驗證，到產出可交付製造的版圖檔的軟體工具與方法。

為了解決電晶體數量過於龐大的問題，盡量是能夠自動化就自動化

自動化的下一步就是抽象化，人類處理複雜問題的方法，是隱藏細節、分層思考。

## 流程
設計晶片的基本策略是由抽象到具體，人寫最上層，往下的轉換由工具自動完成，並在過程中不斷檢查。
- 1.系統與架構設計
- 2.暫存器傳輸層級（RTL）設計
- 3.功能驗證
- 4.邏輯合成
- 5.實體設計
-  6.時序與功耗分析
-  7.物理驗證與簽核
-  8.製造交付

整體來說就三步
```
設計（1–3）→ 實作（4–5）→ 簽核與交付（6–8）
```
### 人類負責的部分
人負責決定要做什麼（架構、RTL、規格、限制條件）與判斷結果對不對、要不要改；工具負責把設計一層層轉換下去，並大量地檢查。

階段 | 人做什麼
--|--
1.系統與架構|決定晶片要做什麼、效能與功耗目標
2.RTL 設計|寫出暫存器與資料流
3.功能驗證|寫 testbench 與測試案例
4–5.合成與實體設計|人下限制條件（目標時脈、面積、功耗）
6–7. 時序、功耗與簽核|工具產生報告，人要判讀
8.交付 | 最終決定能否送到晶圓廠

## 第 1 課：閃爍的 LED
接下來的會開始做 RTL 的部分
>RTL（Register Transfer Level，暫存器傳輸層級）的意思是用「暫存器」和「暫存器之間的資料傳輸」來描述電路。 

這裡只看`Blinky`，是因為這才是要燒進 FPGA 的硬體設計。
底下的`TestBlinky`是驗證用的

```verilog
module Blinky #(
    param WIDTH: u32 = 24, // 設定計數器的位元數，以 12 MHz 時脈計算
) (    
    i_clk : input  clock   , // 12 MHz
    i_rst : input  reset   , // 板上按鈕 BTN_N（按下 = 重設）
    o_ledr: output logic   , // 板上紅燈（低電位點亮）
    o_ledg: output logic   , // 板上綠燈（低電位點亮）
    o_led : output logic<5>, // 擴充板 LED1..LED5（高電位點亮）
) {
    var cnt: logic<WIDTH>;
    //每個時脈正緣+1，重設時歸零
    always_ff {
        if_reset {
            cnt = 0;
        } else {
            cnt = cnt + 1;
        }
    }

    assign o_ledr = !cnt[WIDTH - 1]; // 最高位元為 0 時紅燈亮。
    assign o_ledg = cnt[WIDTH - 1]; // 最高位元為 1 時綠燈亮。兩燈剛好交替
    assign o_led  = cnt[WIDTH - 1:WIDTH - 5]; //取最高 5 位元
}

```
