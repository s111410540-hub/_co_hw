# 數字炸彈 Number Bomb（Project 9）

用 Jack 語言寫的猜數字派對遊戲。電腦在 **1～100** 之間藏一顆炸彈，玩家輪流猜數字，
每猜一次，炸彈可能所在的範圍就會縮小；**猜中炸彈的人就輸了**。

## 玩法

1. 標題畫面按 `1` 選「雙人對戰」，按 `2` 選「對電腦」。
2. 輪到你時，用數字鍵輸入要猜的數字：
   - `Backspace` 刪掉最後一個數字
   - `Enter` 送出
   - 超出目前範圍會顯示提示，請重新輸入
3. 沒猜中的話，畫面會告訴大家炸彈比這個數字大還是小，範圍條同步縮短。
4. 猜中炸彈會播放爆炸動畫，接著顯示誰輸、誰贏、總共猜了幾次。
5. 按 `Enter` 再玩一局，按 `Q` 離開。

## 執行方式

```powershell
python ..\..\11\JackCompiler.py .      # 或用官方 tools\JackCompiler.bat
```

用 VMEmulator 載入 `NumberBomb` 資料夾，選 **No animation**，按 Run，
再點一下鍵盤圖示，按鍵才會送進程式。

## 程式架構

| 檔案 | 說明 |
|---|---|
| `Main.jack` | 程式進入點：標題畫面 → 一局遊戲 → 詢問是否再玩 |
| `NumberBombGame.jack` | 一局遊戲的狀態（範圍、炸彈、輪到誰）與流程、畫面繪製 |
| `NumberInput.jack` | 讀取鍵盤輸入的數字（只接受數字、可刪除、限制位數） |
| `Random.jack` | 亂數產生器（seed' = 171·seed mod 30269，用 Schrage 方法避免 16 位元溢位） |
| `Ui.jack` | 共用的輸出、按鍵讀取、標題與結束畫面、炸彈和爆炸圖形 |

## 設計重點

- **亂數種子**：Hack 電腦沒有時鐘，所以在等待按鍵時不斷呼叫 `Random.tick()`，
  讓炸彈位置取決於玩家按鍵的時間點，每局都不一樣。
- **範圍條**：1～100 每個數字對應 4 個像素寬，黑色部分就是炸彈可能在的範圍。
- **記憶體管理**：Jack 的字串常值每次執行都會配置新的 `String`，
  所以印字一律透過 `Ui.print`，印完就 `dispose()`，連續玩很多局也不會耗盡 heap。
  遊戲物件在每局結束時也會 `dispose()`。
- **電腦玩家**：在目前範圍內隨機猜，並加上「思考中...」的延遲，讓節奏比較自然。
